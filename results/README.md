# results/ 阅读说明

本目录存放 SPEC 评审与实现的历史报告（原始文件逐字节一致，md5 见 `../CHECKSUMS.md`）。
评审流程：每个 SPEC 版本经两路独立盲审（两路模型互不知晓对方评审）+ 一份合并评审（去重后的问题清单、修复项、裁决项）+ 自查，通过后交 owner 冻结批准。
